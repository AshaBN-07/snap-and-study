# 📚 Snap & Study

Snap & Study is an AI-powered study assistant.

## Features

- 📷 Upload JPG, JPEG, or PNG study images
- 🤖 Get simple explanations using Gemini Vision
- 📝 Understand key concepts and important points
- 🎓 Beginner-friendly study guidance

## Technology

- Python
- Streamlit
- Google Gemini API

## How it works

Upload a study image → Gemini analyzes it → Snap & Study provides a simple explanation and key concepts.
